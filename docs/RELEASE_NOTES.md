OneYes ComfyUI v0.1.11，基于 ComfyUI 0.46.0。

- 默认独立使用：启动只恢复本软件登录状态，不再尝试连接主客户端。直接登录、二次验证、Key 新建与选择、本机加密保存和原任务取回均可独立运行，复用主客户端保留为可选入口。
- 增加本软件内的 OneYes 网站登录窗口，在官网完成验证码、登录协议等步骤后自动接入账号和 Key。网站与画布隔离，登录结果经服务端验证，关闭后清除临时会话；无需主客户端代为验证。
- 修复 GPT 图片已生成但下载报“素材下载地址无效”：兼容代理 Fake-IP DNS（198.18.0.0/15）和代理环境变量，保留 HTTPS 校验，继续阻止回环、内网和元数据地址。已完成任务下载失败后仍能取回原结果，不重复生成扣费。
- 新建 OneYes 生图节点默认模型更新为 gpt-image-2；已有工作流的模型和参数保留，仍可按当前 Key 选择其他模型。四个平台验证独立登录及原版 GPT 图片工作流，使用隔离测试接口，不产生付费请求。

- 修复 macOS 无法退出程序：工作流阻止关闭时显示“返回保存／退出”原生确认，取消后画布和引擎继续运行，确认后再停止后台引擎并退出。菜单、Command-Q 和系统退出使用同一流程，关闭窗口仍缩到托盘。
- 修复启动中退出可能遗留后台引擎的问题；退出只执行一次清理，等待启动收尾后结束程序。四个平台用真实桌面和引擎验证关闭、重新打开、取消退出和确认退出。

- 修复 ElevenLabs 原版节点被误报为“缺失节点包／引擎版本过低”：恢复 8 个原版节点定义、输入参数、输出插槽和工作流连线。原版音色选择器可直接本地执行，无需额外 pip 包或 Manager。
- OneYes 当前未提供 ElevenLabs 语音接口，7 个云端操作明确显示“OneYes 暂未接入”及原因；不会调用 Comfy 代理、上传样本或重复收费。此版本不声称已提供语音生成或声音克隆服务。
- 补齐原版高斯点云 SPZ v4 节点的 Zstandard 依赖，随安装包和 OTA 一起提供，无需用户手动执行 pip。
- 四个平台逐项核对原版内置节点注册；在隔离、断网、中文路径下实际执行边缘检测、形态学、超分模型加载与放大、音频读写、视频编码与解码和 SPZ v4 导入／PLY 导出。无需下载模型或产生收费请求。
- 深度接入 19 个原版 API 节点：GPT 图片与 ChatGPT Responses、Claude、Gemini / Nano Banana、Grok 图片与视频及文件 / 高级选项。保留原节点 ID、参数、插槽与输出，支持原工作流导入。
- 平台 Key 独立加密保存与选择，首次连接复用已有平台 Key；Grok 图片与 Video 分组分别路由，避免混用。节点模型选择可刷新当前分组权限。
- 原分辨率上传多图，保留遮罩、涂鸦、透明通道、批次数量和高级参数。GPT 异步图片与 Grok 视频保存原回执，重启后原参数取回，不自动重复付费提交。
- 右上角账号入口改为 OneYes，未登录显示“OneYes 登录”；登录后显示账号名，悬停显示余额或连接状态。
- 点击账号按钮及原登录入口直接打开原生 OneYes 账户页，支持直接登录、二次验证码、复用客户端登录态与手动配置 Key。
- 移除原 Comfy 登录提示与 SSO／Google／GitHub 登录弹窗，新增 OneYes 官网注册和找回密码入口。
- 保留 ComfyUI 应用图标、原生画布与工作流；OneYes 登录态与 Comfy Org 身份独立。
- 四个平台验证真实账号按钮点击、登录状态更新、账户链接、权限隔离、原生工作流及 19 个原版节点的协议契约，再构建签名 OTA；测试不产生付费生成。

支持范围以 docs/NATIVE_NODES.zh-CN.md 为准；其他供应商专有接口仍禁用。OneYes 未提供的模型不伪装为可用能力，费用以 OneYes 为准。

支持 Windows x64、macOS Apple Silicon、Linux x64／ARM64；Linux 提供 AppImage、DEB、RPM。安装包内置完整运行依赖，更新保留登录状态、Key、工作流和任务。macOS 当前为 ad-hoc 自签名，未经过 Apple 公证。

完整源码见 Source.tar.gz；ComfyUI 引擎采用 GPL-3.0-or-later，图标来源与授权见 docs/THIRD_PARTY.md。
