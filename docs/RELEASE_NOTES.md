OneYes ComfyUI v0.1.20，基于 ComfyUI 0.46.0。

- 更新瘦身：Windows、macOS 和 Linux 的八种 OTA 格式统一支持分块增量，只下载有变化的内容，保留断点续传、完整性校验及失败重试。
- 安装包精简：去除重复的原前端资源和 CPU 环境用不到的 GPU 编译内核，保留独立运行环境、全部原版节点依赖、模板预览和许可证。
- 关于页显示实际下载量和已复用的数据量；服务临时故障时保留增量进度，避免意外转为整包重复下载。
- 自动清理过期 OTA 缓存，仅保留当前基包和正在下载的新版。更新后自动重新打开，账户、Key、工作流和云端任务保留。

旧客户端首次迁移、首次安装或没有可用基包时仍下载完整安装包；后续有对应基包及索引的更新自动复用。发布包均通过四个平台的原生界面、离线工作流和签名校验。

v0.1.18／v0.1.19 未正式发布：固定增量测试样本，并补齐索引请求临时失败时保留增量模式的验证，以 v0.1.20 完成统一发布。
