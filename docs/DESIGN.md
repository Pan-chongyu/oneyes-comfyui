# OneYes ComfyUI 桌面界面

配置页围绕“连接 Key，打开节点工作流”这一条路径。保留原 ComfyUI 画布，不增加另一套编辑器。

颜色：深蓝灰底 #191B20，侧栏与输入面 #22252D，分隔线 #373B46，主要文字 #E2E5EE，次要文字 #979EAE，操作色 #ABB5FA。跟随 OneYes 应用图标，减少与原画布的视觉割裂。

字体：系统中文无衬线，Windows 使用微软雅黑 UI，macOS 使用苹方。25px 页标题，14px 正文，12px 次要信息。

布局：左侧固定设置导航，右侧 Key 表单和运行状态；标题栏融入同一背景。任务回执、完整模型名称和 OTA 各自有独立页面。运行状态靠近打开画布按钮，用户能直接看到依赖下载、启动、错误与重试。

避免仪表盘卡片网格；主要动作突出，其他字段只在需要时展开。仅运行中的状态点使用呼吸动画，尊重减少动态效果设置。
