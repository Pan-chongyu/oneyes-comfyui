# OneYes ComfyUI 桌面界面

启动直接进入原 ComfyUI 画布，不显示独立设置窗口，也不自动打开模板推荐。

保留原生设置框、左侧分类、主题与滚动方式。“用户”页替换为 OneYes 账户，用四个标签集中账户与 Key、可用模型、云端任务和软件更新。颜色使用 ComfyUI 主题变量，主要动作使用原生蓝色，辅助操作保持低强调。

字体继承 ComfyUI，21px 页标题、13px 正文、12px 提示。Key 高级选项折叠，图片和文字 Key 并排，窄窗口改单列。标签支持方向键切换，状态通过无障碍提示播报。

原版节点继续使用原生动态参数面板、插槽、队列和输出预览，仅在节点内增加 OneYes 模型选择与设置入口。Claude、Gemini、Grok 图片与 Video 分组的 Key 收在折叠高级区域，普通用户无需面对重复的账户界面。原版 Comfy 积分价格标签不用于 OneYes，费用以 OneYes 为准。

顶部 OneYes 菜单、系统菜单和节点按钮复用原生用户设置框；托盘回到画布。引擎启动时仅在同一窗口显示简短加载状态，失败提供重试和日志目录入口。

右上角使用 OneYes 账号按钮：未登录显示“OneYes 登录”，登录后显示账号名称，悬停显示余额或连接状态。点击直达同一个 OneYes 用户页。注册与忘记密码打开固定的 OneYes 官网页面；不再显示 Comfy 账号、SSO 或第三方登录表单。

避免仪表盘卡片与重复入口。加载动画和交互过渡尊重减少动态效果设置。
